# Mi Piano 3 · El viaje de Bach

Juego de piano para Sarah y David. Empieza por `EMPEZAR-AQUI.md`, luego `PROYECTO.md` (decisiones) y `ESTADO.md` (dónde vamos).

- Código: `src/` · Armar: `node build.js` → `MI-PIANO-3-M3.html` y `web/` (PWA).
- Pruebas (Playwright): `node pruebas/humo.js`, `node pruebas/sesion.js --minutos 15`.
- Voces publicadas: `voces-publicadas/` (copia en `web/voces/`).
- Página de pruebas: https://app.ecofamiliar.org/pruebas/mi-piano-3/
